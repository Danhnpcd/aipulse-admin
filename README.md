# ☁️ AI Pulse 24/7 Unified Cloud Server

Hệ thống máy chủ đám mây độc lập hợp nhất **4 phân hệ chạy 24/7** ngay cả khi máy tính cá nhân đã tắt hoàn toàn:

1. **Web Admin Cockpit (`/`)** — Trung tâm điều hành doanh nghiệp AI 2.5D & API Control Room.
2. **TikTok Fashion AI Studio (`/tiktok-studio/`)** — Phòng thu AI thời trang, Virtual Try-On & Kịch bản 4 cảnh.
3. **AI Pulse News Portal (`https://danhnpcd.github.io/aipulse-news/` & `/news/`)** — Cổng tin tức AI & Công nghệ tự động xuất bản 24/7 (tối ưu Mobile Drawer).
4. **Zalo AI Guardian — SysMind (`/api/zalo/webhook`)** — Trợ lý AI quản trị hệ thống 2 chiều qua Zalo kèm Pop-up lựa chọn nhanh `[1..8]` & công tắc Tạm dừng / Bật lại 24/7 từ xa.

## 🚀 Triển Khai 1-Click Miễn Phí Vĩnh Viễn Trên Render.com

Bấm trực tiếp đường dẫn Blueprint dưới đây để khởi tạo máy chủ Cloud Singapore miễn phí:

👉 **https://dashboard.render.com/blueprint/new?repo=https://github.com/Danhnpcd/aipulse-admin**

Điền 2 biến bảo mật khi Render hỏi:
- `ZALO_BOT_TOKEN`: Mã Bot Token của SysMind trên Zalo Bot Manager.
- `GEMINI_API_KEY`: Mã API Key Google Gemini (Miễn phí từ Google AI Studio).
- *(Tùy chọn)* `DATABASE_URL`: Dán chuỗi kết nối PostgreSQL miễn phí vĩnh viễn từ **Neon.tech** (`postgresql://...`) nếu muốn lưu trữ cơ sở dữ liệu bền vững vĩnh viễn qua các lần nâng cấp container.
